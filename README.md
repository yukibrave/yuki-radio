# yukiラジオ

ゲーム関連・PC関連・日常・その他から、きのうの気になるニュースを毎朝お届けする、HTMLのラジオ番組です。
仕組みは monoradio102/myradio テンプレート（ものラジオ）と同じ形式で、台本（JSON）と音声（mp3）を置くと、ブラウザが字幕・スライド・キャラクター・リンクカードを再生に合わせて動かします。
